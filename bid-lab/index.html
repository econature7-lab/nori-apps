투찰가 계산기

예정가격 = 기초금액 × 사정률 · 낙찰하한금액 = (예정가격 − A값) × 낙찰하한율 + A값
하우재 실측 기준 권고 사정률 100.1 ~ 100.4% · 하한 미달 탈락을 막는 최소선을 먼저 확인하세요.

사정률 구간별 금액

권고 투찰가 = (예정가격 − A값) × (낙찰하한율 + 0.03%p) + A값 · 원단위 절사. ‘권장’ 구간이 하우재 실측 기준 100.1~100.4%입니다.

사정률예정가격낙찰하한금액권고 투찰가구간
A값은 발주처 산식에 따라 다릅니다(기술용역은 0인 경우가 대부분). 실제 투찰 전에는 공고문의 낙찰하한율·A값 적용 여부를 확인하세요. 이 계산기는 본인 의사결정용이며, 타사와 투찰가를 조율하는 데 쓰면 2026-05-28 개정 「공사입찰특별유의서」상 불법 브로커 처벌 대상입니다.

판정 배지 읽는 법

판정은 ① 하우재 보유 업종(4817·4442, 1169는 등록 진행중) ② 요구 업종 조합 ③ 지역제한 ④ 공동수급 허용 ⑤ 규모·상주 조건을 대조해 계산합니다. 최종 판단은 공고문 원문 기준입니다.

협정(전자공동수급) 4단계

  • 1사전 합의 — 전화로 자리(중복 참여) 여부·참여 의향·분담비율·대가 확인. 나라장터에 먼저 올리면 안 됩니다.
  • 2대표사 협정서 작성 — 입찰진행 → 협정 → 분담이행 → 사업자번호로 구성사 조회 → 비율 합계 100% → 저장 → 공개 클릭
  • 3구성사 승인 — 구성사가 공동수급협정서목록에서 동의·승인 (마감 지연의 대부분이 이 단계)
  • 4대표사 최종 제출 — 전원 승인 확인 → 최종제출 → 진행상태 ‘최종제출’ 확인 → 입찰서 제출

실무 목표: 입찰 전날 18:00까지 완료. 협정서 제출기한은 공고문 기준(입찰 마감과 다를 수 있음).

전문소방 1489 vs 일반소방 1490·1491

1489는 소방기술사를 두는 상위 업종으로 연면적·제연설비 제한 없이 모든 특정소방대상물을 설계합니다. 1490·1491은 연면적 3만㎡(공장 1만㎡) 미만이면서 제연설비가 없는 건까지만 가능합니다.

  • 1489 요구 공고 → 건창 불가(미보유). 나비·국제·씨엔아이로 문의
  • 1490·1491만 요구 → 건창·서원·예다로 충분
  • 공고 ‘허용업종’에 1489가 열려 있으면 1489 업체가 오히려 유리
